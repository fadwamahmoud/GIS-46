Introduction to
the Back End

What happens behind the scenes when you open a website — and where Node.js fits in.

The Big Picture

Every website has two sides

Front End

What the user sees and interacts with in their browser — the interface.

HTML CSS JavaScript

Back End

Everything that runs on the server, hidden from the user — the engine.

Server App Logic Database

Front End

The user sees this — always three languages

HTML — Structure. The skeleton of every page. Headings, paragraphs, buttons.

CSS — Presentation. Colors, fonts, layout, spacing.

JavaScript — Behaviour. What happens when you click, type, or scroll.

These three are fixed. Every browser in the world speaks HTML, CSS, and JavaScript — nothing else.

Back End

The server can use almost any language

The browser never runs your back-end code — it only sees the result.

As long as the server sends back valid HTML, CSS, and JS, the browser is happy.

That freedom means many different languages can power a website's back end.

Back End

The back end has 3 main parts

Server — The computer that listens for requests and sends back responses.

Application — The code that decides what to do with each request (your Node.js app lives here).

Database — Where data is stored and retrieved (users, posts, orders, etc.).

How It All Connects

The request–response cycle

Browser
User types a URL or clicks a link
→ HTTP request
Server
Receives and routes the request
→ query
Database
Stores & retrieves data
→ data
App Logic
Builds the HTML response
→ HTTP response
Browser
Renders the page for the user

Node.js

Why are we learning Node.js specifically?

You already know JavaScript. Node.js lets you use it on the server too — no new language to learn from scratch.

One language, full stack. Write the front end and the back end in the same language.

Widely used in industry. Companies like Netflix, LinkedIn, and Uber use Node.js on their servers.
